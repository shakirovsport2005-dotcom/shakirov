# Иллюстрации

Два изображения созданы ИИ специально для ХакКампуса: работа студенческой команды и университетский кампус. Это не фотографии реальных людей или реального мероприятия. Исходные PNG сохранены рядом, для интерфейса используются оптимизированные WebP, встроенные в страницу. Загрузка внешних изображений не требуется.
